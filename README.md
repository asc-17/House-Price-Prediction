# House Price Predictor

A simple House Price Predictor to predict house price with just `area`(in sq.m) of a house. Prediction using linear regression model.

## Tech Stack Used
- **Frontend / Deployment**: Flask
- **Machine Learning**: Linear Regression
- **Data Visualization**: Matplotlib, NumPy
- **Environment**: Python 3.14
